# Task 20 – Typing Speed Test

A responsive and interactive **Typing Speed Test** web application built using **HTML5, CSS3, and JavaScript**.

The application displays a random passage, measures typing speed and accuracy in real time, highlights typing errors, and provides a restart option.

## 🔗 Live Demo

https://silambarasanc199-jpg.github.io/task-20-typing-speed-test/

## 📌 Project Overview

This project was developed as part of the **Veda Technology Web Development Internship – Task 20**.

The project focuses on practicing JavaScript concepts including text comparison, keyboard events, timers, DOM manipulation, real-time UI updates, and performance calculations.

## 🎯 Task Objective

Build a typing speed test that:

- Displays a random typing passage
- Starts the timer on the first keystroke
- Compares typed text with the target passage
- Highlights typing errors in real time
- Calculates Words Per Minute (WPM)
- Calculates typing accuracy
- Provides restart functionality
- Works on mobile and desktop devices

## ✨ Features

### 📝 Random Passage

A random passage is selected for each typing test.

### ⏱️ Automatic Timer

The timer starts automatically when the user begins typing.

### 🔴 Real-Time Error Highlighting

The application compares every typed character with the target passage.

- Correct characters are identified
- Incorrect characters are highlighted
- Typing progress is updated live

### ⚡ WPM Calculation

Typing speed is calculated using:

WPM = Correct Characters ÷ 5 ÷ Time in Minutes

### 🎯 Accuracy Calculation

Accuracy is calculated using:

Accuracy = Correct Characters ÷ Typed Characters × 100

### 🔄 Restart Function

Users can restart the test and receive a new passage without refreshing the browser.

### ⌫ Backspace Support

Users can use backspace to correct typing mistakes during the test.

### 📱 Responsive Design

The application is optimized for:

- Mobile phones
- Tablets
- Laptops
- Desktop computers
